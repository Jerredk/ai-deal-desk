8. Engineering Walkthrough

  1. Increment 1 — Deterministic foundation. SaaS margin math and approval tiers in Python/SQLite (18% list-ARR COGS, $150/hr services, Net-60/90 penalties, 72% hard floor).
  2. Increment 2 — ACI tools + Hybrid RAG + cost ledger. Poka-yoked schemas; local 384-d hashing embeddings + BM25 with Reciprocal Rank Fusion; pinned Anthropic rate card (as of 2026-11-21).
  3. Increment 3 — Raw Messages agent. Versioned prompts: v1 baseline BM25 + basic tools (no cache); v2 poka-yoke tools + hybrid RAG + prompt caching; v3 = v2 + Evaluator-Optimizer critic.
  4. Increment 4 — Eval harness. Deterministic graders + independent Opus judge (claude-opus-4-6; agent claude-sonnet-4-6).
  5. Increment 5 — 60-run empirical suite. 20 golden cases × 3 versions. Operational fix: v3/GE-020 required max_tokens 2048 → 4096 after JSON truncation.
